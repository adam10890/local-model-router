# Ponytail 0.5.0 Simplification Plan

> Execute this plan on `dev/ponytail-0.2.1`, then promote the verified branch to
> `ready/ponytail-0.5.0`. The requested `0.2.1` cannot be used because `main` is
> already `0.4.0`; the additive embeddings endpoint makes this a `0.5.0` minor release.

**Goal:** Apply the accepted ponytail audit without changing supported router
behavior, preserve the restored startup/model/dashboard work, and publish one
reviewable PR.

**Approach:** Remove only duplicate, unused, or non-serving paths. Keep
`BackendManager`, the HTTP router, SQLite fleet telemetry, active context-tier
planning, `local_only`, and every current public endpoint. Every deletion starts
with a failing or characterization test and ends with the smallest passing diff.

**Stack:** Python 3.12, Starlette, aiohttp, pytest, static Alpine.js dashboard,
PowerShell/BAT launchers.

# 0016. Use adr-steward to maintain the decision log

Date: 2026-11-10

## Status

Accepted 2026-11-23 (v1.0)
> In the context of Imperium's existing decision log, facing agents that must record the next decision without rewriting the ones already accepted, we decided for adr-steward and the Nygard template and neglected a hand-maintained index and a supersede-all rewrite, to achieve a lintable append-only log, accepting a generated index and one founder-directed wording pass on ADR-0001–0015, because those decisions stay in force and their numbers are already on main.

## Context

Imperium already has fifteen accepted records in `docs/adr/`, numbered 0001 through 0015, written in a short Nygard-like shape. The index was edited by hand and also pointed at `GOALS.md`, the beta roadmap, `hot-cold-policy.md`, and `task-disclosure.md`. Those pointers now live in `docs/AGENTS.md`.

Nothing in the repository checked numbering, two-way supersede links, or an edit to an accepted Context, Decision, or Consequences. ADR-0007 says agents propose and the founder decides.

On 2026-11-10 the founder directed two things in the same breath: adopt this tool, and fill the wording gaps in the fifteen records. A lint of the log as it stood on main reported one error, the hand-written index, and 29 warnings: every Decision lacked "We will", and fourteen Consequences sections did not state a downside. ADR-0002 already recorded downsides in the section after Consequences, which the lint happened to count.

The forces pull apart. A generated index stays complete, and the hand-written index carried navigation the generator drops. A stricter template would lint more cleanly, and replacing an accepted body would erase the text that was accepted. The founder asked for the gaps to be filled, not for the decisions to change. Each file still contains its previous sentences, under a new opening sentence and above one new downside line.

`tools/adr.py init` would write `0001-record-architecture-decisions.md`. ADR-0001 on main is already `0001-hermes-primary-client.md`. That number stays where it is.

The process choice can be reversed until the lint workflow is required on main. Changing what the fifteen records decide is a different act, and it is not this one.

## Decision

We will maintain `docs/adr/` with `python tools/adr.py` and the Nygard template. New records are created with that tool, start as Proposed, and become Accepted only after the founder approves and an agent runs `accept`. `docs/adr/README.md` is generated by the tool and is not edited by hand.

This covers the decision log only. It does not change routing, disclosure, fleet behavior, or the substance of ADR-0001 through ADR-0015.

We rejected leaving the log hand-maintained, because nothing then checks the index or a supersede link. We rejected superseding all fifteen with rewritten copies, because the decisions did not change and a number already on main is not reused. Nygard stays the template because one founder approves, and the existing records are already in that shape.

## Consequences

Positive: the next decision gets the next number, the index matches the files, and lint fails on a broken structure. Agents can read an Accepted ADR as a constraint.

Negative: the generated index no longer carries the four hand-written links; `docs/AGENTS.md` does. ADR-0001–0015 now contain sentences that were not in the first accepted text, so the file is not a photograph of the day it was accepted. The previous sentences are still there. `tools/adr.py` allows that diff against a base Decision that does not yet say "We will", and only when the old Decision and Consequences text are still present and the Context is untouched. After this text is on main the base Decision will already say "We will", and that allowance stays closed.

Neutral: `.github/workflows/adr-lint.yml` runs the linter without `--strict`. Do not run `init`. The wording pass on the fifteen records is the founder's instruction recorded here; it is not a sixteenth decision.

Compliance: `python tools/adr.py lint` and `python tools/adr.py lint --base origin/main` both exit 0.

Review trigger: reopen this record if the founder wants the AWS template, or if a later edit to an accepted Decision or Consequences still passes `lint --base` after this record is on main.

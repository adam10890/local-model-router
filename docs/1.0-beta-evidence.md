### Hermes during Studio baseline (G2)

Q4 / Q7 stage 1, 2026-11-23. The tests use the in-process Imperium app,
fake Studio and backend calls, and a virtual Hermes retry clock. No renderer,
gateway, or WhatsApp transport runs. G2 stays Partial.

```powershell
.\.venv\Scripts\python.exe -m pytest tests\test_gpu_swap_api.py tests\test_hermes_studio_launch.py -q -rxX
```

| Hermetic case | Result |
| --- | --- |
| [Named CPU route during a Studio lease](../tests/test_gpu_swap_api.py) | Strict expected failure. The named CPU pin reaches its fake backend before the lease. The CPU and strong routes both return `503 gpu_leased_by_studio`, with `Retry-After: 120` and zero forwards while leased. Running the test with `--runxfail` fails at that rejection. |
| [Post-tool launch during continuous lease](../tests/test_hermes_studio_launch.py) | With three primary attempts, no fallback provider, and zero recovery cycles, the driver ends at 240 simulated seconds after three requests and emits no launch acknowledgment. With five eligible recovery cycles enabled, it ends at 2,040 simulated seconds after 18 requests and emits no launch acknowledgment. |
| [Post-tool launch after simulated release](../tests/test_hermes_studio_launch.py) | With release at 120 simulated seconds, the second request reaches the fake strong backend and yields a simulated launch acknowledgment at that time. |

The virtual driver uses the primary retry count, recovery reset, and
`Retry-After` behavior from Hermes `v0.23.3` at `caafe5389a`. See the
[retry loop](https://github.com/NousResearch/hermes-agent/blob/caafe5389ae585ef77387a962aee05b1bcf17029/agent/conversation_loop.py#L1550-L1579),
[exhaustion and backoff](https://github.com/NousResearch/hermes-agent/blob/caafe5389ae585ef77387a962aee05b1bcf17029/agent/turn_api_error.py#L374-L437),
[auto-recovery](https://github.com/NousResearch/hermes-agent/blob/caafe5389ae585ef77387a962aee05b1bcf17029/agent/turn_recovery_autorecover.py#L39-L112),
and [recovery default](https://github.com/NousResearch/hermes-agent/blob/caafe5389ae585ef77387a962aee05b1bcf17029/agent/agent_init.py#L1274-L1286).
Run time in a real chat also depends on gateway timeouts, interruption,
diagnostic delivery, and the active recovery setting. CPU placement and live
end-to-end behavior remain unverified.
